## 快速开始

### 环境要求

- **Node.js**: 18.0 或更高版本
- **npm**: 8.0 或更高版本
- **操作系统**: Windows / macOS / Linux

### 安装步骤

```bash
# 1. 克隆项目
git clone https://github.com/YoloBird/YoloToDo.git
cd YoloToDo

# 2. 安装依赖
npm install

# 3. 启动服务
npm start
```

### 访问应用

启动成功后，打开浏览器访问：

```
http://localhost:3000
```

| 项目 | 值 |
|------|-----|
| 用户名 | `admin` |
| 通知邮箱 | `admin@todo.local` |
| 密码 | `admin123` |

> ⚠️ **安全提示**: 首次登录后请立即修改默认密码！

## 功能详解

### 1. 待办清单

待办清单是系统的核心模块，提供完整的任务管理能力。

#### 1.1 创建待办

创建待办时可设置以下字段：

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| 标题 | 任务的简短描述 | ✅ 必填 |
| 内容 | 任务的详细说明，支持 Markdown 格式 | ✅ 必填 |
| 格式 | 纯文本 / Markdown | 可选，默认纯文本 |
| 分类 | 工作 / 学习 / 生活 / 健康 / 其他 | 可选 |
| 优先级 | 高 / 中 / 低 | 可选，默认中 |
| 颜色 | 9 种颜色可选 | 可选 |
| 重要标记 | 星标标记重要任务 | 可选 |
| 截止日期 | 任务需要完成的日期时间 | 可选 |
| 提醒时间 | 在指定时间发送提醒 | 可选 |
| 提醒方式 | 邮件 / Telegram | 可选 |
| 标签 | 自定义标签，支持多个 | 可选 |

#### 1.2 Markdown 支持

当格式设置为 Markdown 时，支持以下语法：

- **标题**: `# H1` `## H2` `### H3`
- **强调**: `**粗体**` `*斜体*` `~~删除线~~`
- **列表**: 有序列表、无序列表、任务列表
- **代码**: 行内代码、代码块（支持语法高亮）
- **引用**: `> 引用内容`
- **链接**: `[文字](URL)`
- **表格**: 标准 Markdown 表格语法

#### 1.3 颜色系统

提供 9 种预设颜色用于视觉区分：

| 颜色 | 色值 | 建议用途 |
|------|------|----------|
| 红色 | `#ef4444` | 紧急任务 |
| 橙色 | `#f97316` | 重要任务 |
| 黄色 | `#eab308` | 需关注 |
| 绿色 | `#22c55e` | 进行顺利 |
| 青色 | `#14b8a6` | 学习相关 |
| 蓝色 | `#3b82f6` | 工作相关 |
| 紫色 | `#8b5cf6` | 创意想法 |
| 粉色 | `#ec4899` | 生活相关 |
| 灰色 | `#6b7280` | 低优先级 |

#### 1.4 优先级

| 级别 | 显示 | 说明 |
|------|------|------|
| 高 | 🔴 红色标识 | 需要立即处理的紧急任务 |
| 中 | 🟡 黄色标识 | 正常优先级的日常任务 |
| 低 | 🟢 绿色标识 | 可以稍后处理的任务 |

#### 1.5 分类管理

系统预设 5 个分类，用于组织不同类型的任务：

- **工作**: 职场相关任务
- **学习**: 学习、培训、考试相关
- **生活**: 日常生活事务
- **健康**: 运动、医疗、作息相关
- **其他**: 未归类任务

#### 1.6 搜索与筛选

**搜索功能**:
- 支持关键词搜索
- 搜索范围包括：标题、内容、标签
- 即时搜索，输入即显示结果

**筛选选项**:

| 筛选项 | 说明 |
|--------|------|
| 全部 | 显示所有待办 |
| 未完成 | 只显示未完成的待办 |
| 已完成 | 只显示已完成的待办 |
| 重要 | 只显示标记为重要的待办 |
| 今天 | 只显示今天创建的待办 |
| 按分类 | 按工作/学习/生活等分类筛选 |

**排序选项**:

| 排序方式 | 说明 |
|----------|------|
| 最新优先 | 按创建时间倒序（默认） |
| 最早优先 | 按创建时间正序 |
| 优先级高优先 | 高优先级排在前面 |
| 优先级低优先 | 低优先级排在前面 |
| 标题 A-Z | 按标题字母顺序 |
| 标题 Z-A | 按标题字母倒序 |

#### 1.7 批量操作

- **一键完成所有**: 将所有未完成待办标记为已完成
- **分页显示**: 支持 6 / 9 / 12 / 15 条每页

#### 1.8 提醒功能

系统支持两种提醒方式：

**邮件提醒**:
- 需要配置 SMTP 服务器
- 支持 Gmail、QQ邮箱、企业邮箱等
- 提醒邮件包含任务标题、内容、截止日期

**Telegram 提醒**:
- 需要创建 Telegram Bot 并获取 Token
- 需要在设置中绑定 Chat ID
- 实时推送提醒消息

**提醒调度**:
- 系统每分钟检查一次待发送的提醒
- 到达提醒时间后自动发送
- 发送成功后标记为已提醒，不会重复发送

#### 1.9 导入导出

**导出**:
- 格式: JSON
- 内容: 当前用户的所有待办数据
- 文件名: `notes_YYYY-MM-DD_时间戳.json`

**导入**:
- 支持方式: 选择文件 / 粘贴 JSON 文本
- 导入策略:
  - **合并导入**: 保留现有数据，追加导入数据
  - **覆盖导入**: 清空现有数据，只保留导入数据
- 数据校验: 自动验证标题、内容是否为空

### 3. 时光看板

时光看板提供任务完成情况的可视化分析。

#### 3.1 日历视图

- 以月历形式展示任务分布
- 每天显示该日创建/截止的任务数量
- 点击日期可查看当天任务详情
- 支持月份前后切换

#### 3.2 活动热力图

- 类似 GitHub 贡献图的热力图展示
- 颜色深浅表示当天活动强度
- 鼠标悬停显示具体数值
- 展示最近 12 周（约 3 个月）的数据

**热力图颜色等级**:

| 等级 | 颜色 | 任务数量 |
|------|------|----------|
| 0 | 浅灰 | 0 个 |
| 1 | 浅绿 | 1-2 个 |
| 2 | 中绿 | 3-4 个 |
| 3 | 深绿 | 5-6 个 |
| 4 | 墨绿 | 7+ 个 |

#### 3.3 统计数据

**本周统计**:
- 本周新建任务数
- 本周完成任务数
- 本周完成率

**本月统计**:
- 本月新建任务数
- 本月完成任务数
- 本月完成率
- 日均创建数

**趋势分析**:
- 与上周/上月对比
- 完成率变化趋势

### 4. AI 智能助手

AI 助手提供智能化的任务管理辅助功能。

#### 4.1 智能对话

与 AI 进行自然语言对话，可以：

- **查询任务状态**: "我今天有什么任务？"
- **获取建议**: "今天我应该优先做什么？"
- **效率分析**: "分析一下我这周的完成情况"
- **任务规划**: "帮我规划一下明天的安排"

**对话特点**:
- AI 了解你的所有待办和想法数据
- 根据任务优先级、截止日期给出建议
- 支持上下文连续对话
- 对话历史自动保存

#### 4.2 多对话管理

- **创建对话**: 点击"新对话"开始新话题
- **对话列表**: 左侧显示所有历史对话
- **对话标题**: 自动根据首次对话内容生成
- **删除对话**: 可删除不需要的历史对话
- **切换对话**: 点击对话标题切换

#### 4.3 快捷创建

使用自然语言描述任务，AI 自动解析为结构化数据：

**示例输入**:
```
明天下午3点开项目会议，很重要
```

**AI 解析结果**:
```
类型: 待办
标题: 项目会议
分类: 工作
优先级: 高
重要: 是
截止时间: 明天 15:00
提醒时间: 明天 14:30
```

**支持的时间表达**:
- 今天、明天、后天
- 下周一、下周五
- 3点、下午3点、15:00
- 3月15日、3/15

**支持的优先级关键词**:
- 高优先级: 紧急、马上、立刻、重要
- 低优先级: 有空、以后、不急

**支持的分类识别**:
- 工作: 会议、报告、项目、同事
- 学习: 考试、作业、课程、复习
- 生活: 购物、家务、约会
- 健康: 运动、体检、吃药

#### 4.4 周报生成

自动生成本周效率报告，包含：

- **本周概况**: 任务完成数、完成率、想法记录数
- **效率分析**: 哪些做得好、哪些需要改进
- **具体数据**: 各分类任务完成情况
- **改进建议**: 2-3 条具体可行的建议

#### 4.5 AI 配置

在设置页面配置 AI 服务：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 启用 AI | 开关控制 | 开启/关闭 |
| Base URL | API 端点地址 | `https://api.openai.com/v1` |
| API Key | 你的 API 密钥 | `sk-xxxx...` |
| 模型 | 使用的模型名称 | `gpt-4o-mini` |

**兼容的 API 服务**:
- OpenAI 官方 API
- Azure OpenAI
- 国内各类中转服务
- 本地部署的兼容服务（如 ollama）

## 系统功能

### 用户认证

**登录机制**:
- 用户名 + 密码登录
- JWT Token 认证
- Token 有效期: 7 天
- 支持"记住登录状态"

**安全保护**:
- 密码使用 bcrypt 加密存储（10 轮盐值）
- 登录失败 5 次后锁定 5 分钟
- 所有 API 请求需要携带 Token

**密码修改**:
- 需要验证旧密码
- 新密码至少 6 位
- 修改成功后需重新登录

### 自动备份

**备份策略**:
- 每天凌晨 3:00 自动执行
- 备份内容: 所有待办和想法数据
- 备份格式: JSON
- 保留策略: 保留最近 7 天的备份

**备份位置**:
```
server/data/backups/
├── backup_2026-01-01_1234567890.json
├── backup_2026-01-02_1234567890.json
└── ...
```

**手动恢复**:
1. 停止服务
2. 将备份文件内容复制到对应数据文件
3. 重启服务

### 提醒调度

**调度机制**:
- 每分钟检查一次待发送的提醒
- 检查条件: 提醒时间已到 + 未完成 + 未发送过
- 发送成功后标记 `reminderSent: true`

**支持的提醒渠道**:

| 渠道 | 配置要求 | 消息内容 |
|------|----------|----------|
| 邮件 | SMTP 服务器配置 | HTML 格式，包含标题、内容、截止时间 |
| Telegram | Bot Token + Chat ID | 纯文本格式，包含标题、截止时间 |

## 配置说明

### 环境变量

在项目根目录创建 `.env` 文件：

```env
# ============ 基础配置 ============
# 服务端口，默认 3000
PORT=3000

# JWT 密钥，用于 Token 签名（请使用复杂随机字符串）
JWT_SECRET=your_very_secure_random_string_at_least_32_chars

# ============ 邮件提醒配置（可选）============
# SMTP 服务器地址
EMAIL_HOST=smtp.gmail.com

# SMTP 端口
EMAIL_PORT=587

# 发件邮箱地址
EMAIL_USER=your_email@gmail.com

# 邮箱授权码/应用密码（非登录密码）
EMAIL_PASS=your_app_password

# ============ Telegram 提醒配置（可选）============
# Telegram Bot Token（从 @BotFather 获取）
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
```

### Gmail 邮件配置

1. 开启 Google 两步验证
2. 生成应用专用密码: Google 账号 → 安全 → 应用密码
3. 填入 `EMAIL_PASS`

### Telegram 配置

1. 在 Telegram 搜索 `@BotFather`
2. 发送 `/newbot` 创建机器人
3. 获取 Bot Token 填入 `TELEGRAM_BOT_TOKEN`
4. 搜索 `@userinfobot` 获取你的 Chat ID
5. 在应用设置中填入 Chat ID

### AI 服务配置

在应用内 **AI 助手 → 设置** 页面配置：

| 提供商 | Base URL | 说明 |
|--------|----------|------|
| OpenAI 官方 | `https://api.openai.com/v1` | 需要国际网络 |
| Azure OpenAI | `https://xxx.openai.azure.com/` | 企业版 |
| 中转服务 | 各服务商提供 | 国内可直连 |
| 本地部署 | `http://localhost:11434/v1` | 如 ollama |

## 常见问题

### Q: 忘记密码怎么办？

直接修改 `server/data/users.json` 文件，将密码重置为默认值，或删除该文件让系统重新生成默认账号。

### Q: AI 功能无法使用？

1. 检查 AI 配置是否正确
2. 点击"测试连接"验证 API 可用性
3. 确认 API Key 有效且有余额

### Q: 提醒没有发送？

1. 检查 `.env` 文件中邮件/Telegram 配置
2. 确认提醒时间已设置且已到达
3. 查看服务器日志是否有错误

### Q: 如何迁移数据到新服务器？

1. 复制整个 `server/data` 目录
2. 在新服务器上恢复该目录
3. 启动服务即可
