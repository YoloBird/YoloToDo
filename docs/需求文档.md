# 产品需求文档

## 项目概述

**项目名称：** 智能便签系统

**版本：** v3.0

**项目定位：** 面向个人用户的生活管理工具，集成任务管理、灵感记录功能。

## 技术规格

### 后端

| 项目 | 技术 |
|------|------|
| 运行时 | Node.js 18+ |
| 框架 | Express 4.x |
| 认证 | JWT (jsonwebtoken) |
| 密码 | bcryptjs |
| 定时任务 | node-cron |
| 邮件 | nodemailer |
| HTTP 客户端 | node-fetch |

### 前端

| 项目 | 技术 |
|------|------|
| 结构 | HTML5 |
| 样式 | CSS3 (原生) |
| 逻辑 | JavaScript (ES6+) |
| 图标 | Font Awesome 6 |
| 字体 | Inter |

### 数据存储

| 项目 | 技术 |
|------|------|
| 格式 | JSON 文件 |
| 用户 | users.json |
| 待办 | notes.json |
| 想法 | ideas.json |

## 安全要求

| 项目 | 实现 |
|------|------|
| 密码存储 | bcrypt 哈希 (salt rounds: 10) |
| 会话管理 | JWT Token (7天有效期) |
| 登录保护 | 5次失败锁定5分钟 |
| API 认证 | Bearer Token |
| XSS 防护 | 输入内容转义 |
| API Key 存储 | 服务端存储，前端脱敏显示 |

| 指标 | 目标 |
