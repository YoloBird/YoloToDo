# 需求文档

## 1. 背景与目标

个人效率管理场景需要一个轻量但覆盖完整流程的系统：记录、执行、复盘与长期沉淀。系统需易部署、可迭代、数据可控。

目标：
- 支持日常待办、想法记录、日记与长期目标管理
- 支持复盘（时光看板）与提醒
- 保证本地开发与服务器部署更新时数据不丢失

## 2. 目标用户

- 单用户使用（个人知识与任务管理）
- WSL 本地开发 + 服务器线上使用

## 3. 功能需求

### 3.1 账号与设置

- 登录/修改密码
- 更新用户名
- 邮件与 Telegram 通知设置
- 测试通知功能

### 3.2 待办清单

- 新建/编辑/删除
- 优先级、分类、标签、颜色标记
- 子任务与完成进度
- 截止日期与提醒
- 完成/归档/恢复
- 列表视图与四象限视图
- 导入/导出

### 3.3 想法记录

- 新建/编辑/删除
- 分类、标签、颜色
- 搜索与排序
- 导入/导出

### 3.4 日记

- 新建/编辑/删除
- 心情、天气、标签
- 日期与区间筛选
- Markdown 支持

### 3.5 长期目标

- 目标创建与状态管理
- 进度跟踪
- 目标记录（灵感/洞察/资料）

### 3.6 时光看板

- 日历视图
- 当日统计
- 周/月概览

## 4. 非功能需求

- 数据持久化：JSON 文件
- 自动备份：每日 03:00
- 移动端适配
- 主题切换
- 安全性：JWT 认证、密码加密存储

## 5. 数据与备份

- 数据目录：`server/data/`
- 建议生产环境单独挂载数据目录
- 提供手动与自动备份机制

## 6. 部署与运维

- WSL 本地开发验证
- Docker Compose 生产部署
- 更新流程可回滚，避免数据丢失

## 7. 不在本期范围

- 多用户权限体系
- 数据库持久化（当前为 JSON 存储）
- 多租户/团队协作
