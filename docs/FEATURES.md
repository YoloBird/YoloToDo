# 功能说明

## 待办清单

- 任务创建、编辑、删除
- 优先级、分类、标签、颜色标记
- 重要标记与完成状态切换
- 截止日期与提醒（邮件/Telegram）
- 子任务管理与完成进度
- 归档与恢复
- 列表视图 / 四象限矩阵视图
- 导入/导出（JSON）

## 想法记录

- 灵感快速记录
- 分类、标签与颜色标记
- 搜索与排序
- 导入/导出（JSON）

## 日记

- 心情、天气、标签
- 日期筛选与区间筛选
- 预览与详情阅读分栏
- Markdown 支持

## 长期目标

- 目标创建与状态管理
- 进度跟踪
- 目标记录：灵感/洞察/资料
- 目标详情与记录编辑

## 时光看板

- 日历视图与每日活动统计
- 周/月趋势概览

## 其他

- 登录与基础账号管理
- 主题切换与移动端适配
- 自动备份（每日 03:00）
